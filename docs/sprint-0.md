# Sprint 0 — Foundation

## Doel

Een clonebare repository met één volledige vertical slice, validatie, generatie en modelonafhankelijke agentcontracten.

## Definition of Done

- Repository bevat model, organisatie en workflow.
- `python tools/validate.py` slaagt.
- `python tools/generate.py` genereert documentatie en Mermaid-output.
- Pull requests worden via GitHub Actions gevalideerd.
- Architectuurlagen bevatten geen providerspecifieke modelkeuzes.
