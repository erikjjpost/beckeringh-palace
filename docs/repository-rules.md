# Repositoryregels

1. `main` is altijd valide en genereerbaar.
2. Wijzigingen verlopen via branches en pull requests.
3. Het model onder `model/` is de bron van waarheid.
4. Gegenereerde output staat niet onder versiebeheer.
5. Agents leveren voorstellen; alleen goedgekeurde wijzigingen worden toegepast.
6. Architectuur blijft onafhankelijk van modelprovider en modelnaam.
