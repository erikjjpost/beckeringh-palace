# Architectuuroverzicht

Beckeringh Palace wordt ontwikkeld als een capabilitygedreven architectural compiler.

```text
Missie
  → Principes
  → Capabilities
  → Services
  → Assets
  → Implementaties
  → Representaties
```

Het model is de bron van waarheid. Documentatie, diagrammen en andere representaties worden daaruit gegenereerd. Agentrollen werken via contracten en voorstellen; modellen en providers zijn vervangbare implementaties.
